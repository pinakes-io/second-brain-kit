# Field map – Second Brain (draft 2026-10-31)

> Belongs to `spec/`. Basis: decisions of 2026-10-31: 9 modules (the 8 from the reference package plus `entscheidungen`) plus a back-reference, one project to start with, personal profile kept apart from the module fields, minimal core, modules in a uniform format plus own areas. Everything here is a **draft**, not signed off.

## 1. What the field map is
The result of interview stage 1. For each module it says: **active yes/no**, **why** (which answer), the **channel** for the detail questions (chat or form) and **who answers**. It is filed as a section in `00_Status`, right next to the version stamp.

## 2. Core (always there, not a module)
- **Skills:** `setup-brain`, `onboarding-interview`, `fact-check`, `weekly-review`, `brain-check`; optional add-on outside the budget: `area-manager`.
- **Documents:** `00_Status` (index, version stamp, field map, filing map), `01_Profile`, `02_Open_Questions`, `Inbox`, `Journal`, `Fact-Ledger`, `Weekly-Plan`, folder `Archive`.
- **Profile:** only the personal profile (`Profilschema.yaml`).

## 6. Rules from the decisions of 2026-10-31 (draft)
- **Form of address (F1):** first question in stage 2 (`Fragen_Stufe2.yaml`, `s2.person.anrede`); stage 1 stays at 2 × 4 questions.
- **Follow-up questions (F2, F3):** Whoever picks "own area (please name it)" is asked for its name (`meta.eigene_bereiche`); whoever names a companion is asked for their role (role, not a name). Neither counts towards the limit of four questions per round.
- **Notes (F5, F6):** For "another language" and for "smartphone only", stage 1 shows a short note (wording in `Fragen_Stufe1.yaml`).
- **Sensitivity tags (F7):** The limits from stage 1 (health, children, names, money) block tags of the same name. Fields and questions with such a tag are dropped in the active modules; the generator records this in `00_Status` in the section Limits.
- **No Claude memory (decision 2026-10-31):** Everything that matters is in Drive documents. The handbook recommends switching off the claude.ai memory or isolating it in the project [interface unchecked]. The account preferences only contain a pointer (see `Konto_Text.md`). "Remember this" always goes to Drive (profile, inbox or journal) with the place of filing in the check line; without write access as an update block, never as a silent "noted".
