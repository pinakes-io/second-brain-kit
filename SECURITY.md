# Security

## What counts

- A weakness in a skill or instruction that lets text in a pasted document, mail or web page take over the assistant (prompt injection).
- A way for a skill to delete, share or overwrite documents without a clear yes.
- A secret, key, token or real personal data that was committed by mistake.

## How to report

Use GitHub's **private vulnerability reporting** (Security tab of the repository), if it is enabled. If it is not, open an issue that says only that you have a security report and ask for a private channel. Do not put details, personal data or secrets into a public issue.

## What to expect

The kit is a draft maintained in spare time. Reports are read and answered as soon as possible, and fixes go into both language packs. There is no bounty.

## Scope

The kit consists of text files and checking scripts. Problems in claude.ai, Google Drive or their connectors belong to Anthropic and Google.
